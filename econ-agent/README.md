# 🤖 الوكيل الاقتصادي الآلي (Telegram) — تشغيل مجاني

يجمع بيانات اقتصادية أمريكية وأسعار الذهب والدولار والأسهم والعوائد وأخبارًا مالية، ثم يرسل إليك تقارير وتنبيهات **بالعربية** عبر Telegram.
**للمعلومات والتنبيه فقط — لا ينفّذ أي صفقات ولا يقدّم توصيات استثمارية.**

## 1) هيكل الملفات
```
econ-agent/
├── .github/workflows/agent.yml   # الجدولة والتشغيل على GitHub Actions
├── econ_agent/
│   ├── main.py          # الأوامر والجدولة (run/morning/movers/calendar/news/alerts/selfcheck)
│   ├── config.py        # الإعدادات من متغيرات البيئة (توقيت المغرب افتراضيًا)
│   ├── indicators.py    # تعريف المؤشرات والأصول ومصادر الأخبار (عدّلها هنا)
│   ├── fred.py          # جلب بيانات FRED ومواعيد الإصدار
│   ├── markets.py       # أسعار الذهب/الدولار/الأسهم (Stooq ثم Yahoo احتياطيًا)
```

## 2) إنشاء بوت Telegram والحصول على chat_id
1. في Telegram افتح **@BotFather** ← أرسل `/newbot` ← اختر اسمًا ثم username ينتهي بـ `bot`.
2. انسخ **التوكن** (يشبه `123456:ABC...`) — هذا هو `TELEGRAM_BOT_TOKEN`. لا تشاركه مع أحد.
3. افتح محادثة مع بوتك الجديد واضغط **Start** وأرسل له أي رسالة (ضروري، وإلا لن يستطيع مراسلتك).
4. افتح في المتصفح: `https://api.telegram.org/bot<التوكن>/getUpdates` وابحث عن `"chat":{"id":123456789` — هذا الرقم هو `TELEGRAM_CHAT_ID`.
   (إن كانت النتيجة فارغة أعد إرسال رسالة للبوت ثم حدّث الصفحة.)

## 3) مفتاح FRED المجاني
سجّل حسابًا مجانيًا في fred.stlouisfed.org ← My Account ← **API Keys** ← Request API Key. هذا هو `FRED_API_KEY`.
(لا يحتاج الوكيل مفاتيح لـ Stooq/Yahoo/RSS. بيانات BLS وBEA تصل عبر FRED وRSS الرسمي.)

## 4) الإعداد والتشغيل على GitHub
1. أنشئ مستودعًا جديدًا على GitHub (يفضّل **عامًا Public** ليكون وقت التشغيل مجانيًا بلا سقف على الأرجح؛ الأسرار تبقى مخفية. إن كان **خاصًا** فالحصة المجانية محدودة، انظر القسم 8).
2. ارفع محتويات هذا المجلد كما هي.
3. Settings ← Secrets and variables ← Actions ← **New repository secret** وأضف: `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` و`FRED_API_KEY`.
4. (اختياري) في تبويب **Variables** غيّر: `TIMEZONE` (الافتراضي `Africa/Casablanca`)، `MORNING_TIME` (`08:00`)، `MOVERS_TIME` (`22:30`)، `WEEKLY_CALENDAR_DAY` (`6`=الأحد)، `WEEKLY_CALENDAR_TIME` (`20:00`).
5. تبويب **Actions** ← فعّل الـ workflows إن طُلب ← افتح `economic-agent` ← **Run workflow**.

## 5) الاختبار (بهذا الترتيب)
1. شغّل يدويًا بالأمر `test-telegram` ← يجب أن تصلك رسالة اختبار.
2. شغّل `selfcheck` وافتح السجل: يختبر FRED وكل رمز سعر لدى Stooq وYahoo وكل RSS. **ما يفشل هنا عدّله في `indicators.py`** (لم تُختبر الروابط والرموز على الشبكة الحية أثناء كتابة المشروع).
3. شغّل `morning` ← تقرير كامل. ثم `calendar` و`movers` و`news`.
4. شغّل `run` (الوضع الدوري). أول تشغيل **يسجّل الحالة الحالية بصمت** (حتى لا تُغرق بالتنبيهات)، وبعدها تصلك الإصدارات الجديدة فقط.
5. محليًا دون إنترنت: `python -m unittest discover -s tests` (23 اختبارًا). ومحليًا مع إرسال حقيقي: انسخ `.env.example` إلى `.env` وصدّر المتغيرات، وللطباعة فقط استخدم `DRY_RUN=1`.

## 6) كيف يعمل (مختصر)
- **كل 15 دقيقة** (أيام العمل): يفحص إصدارات جديدة في FRED، ويفحص RSS، ثم يرسل التقارير المجدولة إن حان موعدها بتوقيت المغرب (نافذة إرسال 3 ساعات لتحمّل تأخر GitHub)، ثم يفحص صحة المصادر.
- **منع التكرار**: ملف `state/state.json` يُحفظ بين التشغيلات عبر `actions/cache`، ويحوي آخر قراءة لكل مؤشر وبصمات الأخبار وما أُرسل اليوم. فشل إرسال Telegram لا يحدّث الحالة، فيُعاد المحاولة تلقائيًا.
- **صحة المصادر**: عند 3 إخفاقات متتالية لمصدر ما تصلك رسالة تنبيه (مرة يوميًا لكل مصدر)، ويظهر آخر نجاح لكل مصدر في التقرير الصباحي.
- **تمييز المصداقية** في كل رسالة: 🟢 بيانات رسمية مؤكدة، 🟡 خبر صحفي غير متحقق منه، 🔵 تحليل آلي بقواعد عامة.
- **التوقعات (consensus)**: لا يوجد مصدر مجاني موثوق وآلي لها، لذلك تظهر "غير متوفر" ولا تُختلق. إن أردت مقارنة حقيقية بالتوقعات، أدخلها يدويًا في `data/consensus.json` قبل الإصدار (انظر المثال داخل الملف)، وإلا قارن التقرير بالقراءة السابقة فقط ويوضح أنها لا تعكس "مفاجأة السوق".

## 7) الخدمات المجانية وحدودها (تحقق من الصفحات الرسمية فقد تتغير)
| الخدمة | الاستخدام | القيود المعروفة |
|---|---|---|
| FRED API | المؤشرات والعوائد ومواعيد الإصدار | مفتاح مجاني؛ الحد الموثّق نحو 120 طلبًا/دقيقة. بيانات الإصدارات تظهر بعد الإعلان بدقائق. **لا يتوفر** عبره: ISM/S&P PMI، Conference Board، سعر الذهب الفوري، DXY نفسه (نستخدم Fed Broad كبديل واسع). |
| Stooq (CSV) | الذهب، الدولار، العملات، المؤشرات | غير رسمي وبلا ضمان أو حدود معلنة؛ بيانات يومية (إغلاق) وقد يتطلب مستقبلًا مفتاحًا. |
| Yahoo Finance (chart) | احتياطي للأسعار | غير رسمي، قد يحجب أو يحدّ طلبات عناوين GitHub (429)؛ تأخير عادةً 15 دقيقة أو أكثر؛ لا تعتمد عليه تجاريًا. |
| RSS (الفيدرالي، BLS، CNBC، MarketWatch) | الأخبار | بلا مفتاح؛ شروط الاستخدام تختلف؛ الروابط قد تتغير. العناوين تبقى بالإنجليزية دون ترجمة. |
| Telegram Bot API | الإرسال | حد تقريبي رسالة/ثانية للمحادثة الواحدة (الحد العام نحو 30 رسالة/ثانية)؛ الرسالة الواحدة 4096 حرفًا (نقسّمها آليًا). |
| GitHub Actions | الجدولة | المستودعات العامة: دقائق مجانية على المشغّلات القياسية. الخاصة: حصة شهرية محدودة (نحو 2000 دقيقة في الخطة المجانية). الجدولة **ليست لحظية**: الحد الأدنى 5 دقائق، وقد تتأخر عند الازدحام أو تُتخطى أحيانًا. المستودعات العامة تُعطَّل جدولتها بعد نحو 60 يومًا من انعدام النشاط. الـ cache يُحذف بعد نحو 7 أيام من عدم الاستخدام. |

**قيود الأسعار الفورية**: النظام ليس لحظيًا؛ التنبيه يصلك بعد دقائق من الإصدار (حتى 15 دقيقة وأكثر)، والأسعار مؤجلة. للتنبيه الفوري الحقيقي تحتاج بيانات مدفوعة أو خادمًا مستمرًا.

## 8) الدقائق على GitHub (مستودع خاص)
15 دقيقة × 18 ساعة × 5 أيام ≈ 1500 تشغيل/شهر ≈ 1500 دقيقة تقريبًا. إن اقتربت من الحد غيّر `cron` إلى `*/30` في `agent.yml` أو اجعل المستودع عامًا.

## 9) أمان
- المفاتيح في Secrets فقط، ولا توجد في الكود. السجلات تُخفي التوكن والمفاتيح (`redact`).
- لا ترفع `.env`. إن تسرّب التوكن: BotFather ← `/revoke`.

## 10) التطوير التدريجي
1. **الآن**: نسخة مجانية بقواعد تحليل ثابتة.
2. **توقعات السوق**: اربط مزوّدًا لديه طبقة مجانية (تحقق من شروطه) داخل `alerts.load_consensus`، أو واصل الإدخال اليدوي.
3. **ترجمة وتلخيص عربي للأخبار**: أضف نموذجًا لغويًا بطبقة مجانية (مثل Gemini API) في `news.py` — شرط أن يلخّص نص الخبر فقط دون إضافة وقائع، مع الإبقاء على الرابط.
4. **مؤشرات إضافية**: أضف `Indicator` جديدًا في `indicators.py` (مثل PCE، مبيعات التجزئة، طلبات إعانة البطالة `ICSA`).
5. **جودة البيانات**: مصدر ثانٍ للذهب، ومقارنة تقاطعية قبل التنبيه.
6. **أوامر تفاعلية** في Telegram (مثل `/gold`) تتطلب خادمًا دائمًا أو webhook (Cloudflare Workers لديه طبقة مجانية).
7. **سجل تاريخي**: حفظ القراءات في CSV/SQLite لتحليل رد فعل الأسواق السابق (وصفي، دون ادعاء سببية).
